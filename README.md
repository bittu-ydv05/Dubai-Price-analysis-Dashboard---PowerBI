# Dubai-Price-analysis-Dashboard - PowerBI
An interactive Power BI dashboard created to analyze Dubai real estate data and generate meaningful insights for investors, buyers, and real estate agents.
This project focuses on transforming raw housing data into easy-to-understand visual insights using Power BI, Power Query, and DAX.


🛠️ Tools & Technologies Used
Power BI – Dashboard creation & visualization
Power Query – Data cleaning & transformation
DAX – Calculated columns & measures
Excel / CSV Dataset – Data source



📂 Dataset Information
The dataset contains the following fields:

Location
Price
Bedrooms
Bathrooms
Size (sqft)
Property Type
Listing Category
Price per Sqft


🧹 Data Cleaning & Transformation

The following preprocessing steps were performed using Power Query:

Removed missing/null values
Corrected data types
Removed duplicate records
Cleaned inconsistent values
Calculated Columns Created
Price per Sqft = Price / Size
Listing Category = Budget / Mid-Range / High-End


📊 Dashboard Features
✅ KPI Cards
Total Listings
Average Price
Average Size
Maximum Price
Average Price per Sqft
✅ Visualizations
Bar Chart → Average Price by Neighborhood
Column Chart → Price by Bedrooms
Interactive Slicers → Bedrooms, Bathrooms, Location, Year
Comparative Analysis of Urban, Suburb, and Rural areas


🔍 Key Insights
Suburban properties have slightly higher average prices.
Properties with more bedrooms generally cost more.
Mid-range properties dominate the market listings.
Interactive filters help users analyze specific market segments.
